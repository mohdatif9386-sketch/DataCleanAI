# DataCleanAI 🤖

**AI-Powered Data Cleaning Assistant for Data Analysts**

DataCleanAI is a Python and Streamlit-based application designed to help data analysts inspect, clean, and improve dataset quality through an interactive interface.

## 🚀 Features

- **CSV & Excel Upload:** Upload datasets for analysis and cleaning.
- **Data Preview:** View dataset records before making changes.
- **Missing Value Handling:** Identify missing values and fill them using available options.
- **Data Type Conversion:** Convert columns to appropriate data types, including integer, float, text, and datetime.
- **Text Standardization:** Standardize text values for improved consistency.
- **Data Quality Checks:** Detect missing values, duplicate rows, and suspicious values.
- **AI-Powered Recommendations:** Get data-cleaning suggestions using the Gemini API.
- **Before & After Comparison:** Review data quality before and after cleaning.
- **Download Cleaned Data:** Export the cleaned dataset.

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Google Gemini API

## ⚙️ Installation & Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/mohdatif9386-sketch/DataCleanAI.git
   ```

2. Open the project folder:

   ```bash
   cd DataCleanAI
   ```

3. Install the required packages:

   ```bash
   pip install -r requirements.txt
   ```

4. Configure your Gemini API key in a local `.env` file. Never upload your API key to GitHub.

5. Run the application:

   ```bash
   streamlit run app.py
   ```

## 🎯 Project Goal

The goal of DataCleanAI is to simplify data preparation by helping analysts identify data-quality issues, apply cleaning operations, and prepare datasets for further analysis.
